# Багатовимірні динамічні масиви

## Мета роботи

Навчитися створювати двовимірні та тривимірні динамічні масиви у C++, обробляти їх вкладеними циклами та правильно звільняти пам’ять.

## Теоретичні відомості

У двовимірному масиві `a[i][j]` індекс `i` позначає рядок, `j` — стовпець. Для `rows` рядків і `cols` стовпців допустимі індекси: `0 <= i < rows` і `0 <= j < cols`. Якщо розміри стають відомі під час виконання, можна виділити масив покажчиків на рядки:

```cpp
int** a = new int*[rows];
for (int i = 0; i < rows; ++i)
    a[i] = new int[cols];

// Робота з a[i][j].

for (int i = 0; i < rows; ++i)
    delete[] a[i];
delete[] a;
```

Кожен рядок виділено окремо, тому весь масив не обов’язково лежить в одному неперервному блоці пам’яті. У тривимірному масиві `a[i][j][k]` індекси означають шар, рядок і стовпець. Пам’ять звільняють у зворотному порядку до виділення: спочатку найглибші масиви, потім масиви покажчиків. Кожному `new[]` має відповідати `delete[]`.

## Приклади

### 1. Сума елементів кожного рядка двовимірного масиву

```cpp
#include <iostream>

int main() {
    int rows, cols;
    if (!(std::cin >> rows >> cols) || rows <= 0 || cols <= 0) {
        std::cerr << "Потрібні додатні розміри матриці.\n";
        return 1;
    }

    int** a = new int*[rows];
    for (int i = 0; i < rows; ++i)
        a[i] = new int[cols];

    for (int i = 0; i < rows; ++i)
        for (int j = 0; j < cols; ++j)
            a[i][j] = i + j + 1;

    for (int i = 0; i < rows; ++i) {
        long long sum = 0;
        for (int j = 0; j < cols; ++j)
            sum += a[i][j];
        std::cout << "Рядок " << i << ": " << sum << '\n';
    }

    for (int i = 0; i < rows; ++i)
        delete[] a[i];
    delete[] a;
}
```

[Файл прикладу](src/example-01-row-sums.cpp)

Для розміру `2 3` рядки мають значення `1 2 3` і `2 3 4`; їхні суми — `6` і `9`.

### 2. Мінімум у кожному стовпці двовимірного масиву

```cpp
#include <iostream>

int main() {
    int rows, cols;
    if (!(std::cin >> rows >> cols) || rows <= 0 || cols <= 0) {
        std::cerr << "Потрібні додатні розміри матриці.\n";
        return 1;
    }

    int** a = new int*[rows];
    for (int i = 0; i < rows; ++i)
        a[i] = new int[cols];

    for (int i = 0; i < rows; ++i)
        for (int j = 0; j < cols; ++j)
            a[i][j] = 3 * i - j;

    for (int j = 0; j < cols; ++j) {
        int minimum = a[0][j];
        for (int i = 1; i < rows; ++i)
            if (a[i][j] < minimum) minimum = a[i][j];
        std::cout << "Стовпець " << j << ": " << minimum << '\n';
    }

    for (int i = 0; i < rows; ++i)
        delete[] a[i];
    delete[] a;
}
```

[Файл прикладу](src/example-02-column-minima.cpp)

Для розміру `2 3` мінімуми стовпців — `0`, `-1`, `-2`.

### 3. Сума елементів кожного шару тривимірного масиву

```cpp
#include <iostream>

int main() {
    int layers, rows, cols;
    if (!(std::cin >> layers >> rows >> cols) ||
        layers <= 0 || rows <= 0 || cols <= 0) {
        std::cerr << "Потрібні додатні розміри масиву.\n";
        return 1;
    }

    int*** a = new int**[layers];
    for (int i = 0; i < layers; ++i) {
        a[i] = new int*[rows];
        for (int j = 0; j < rows; ++j)
            a[i][j] = new int[cols];
    }

    for (int i = 0; i < layers; ++i) {
        long long sum = 0;
        for (int j = 0; j < rows; ++j)
            for (int k = 0; k < cols; ++k) {
                a[i][j][k] = i + 1;
                sum += a[i][j][k];
            }
        std::cout << "Шар " << i << ": " << sum << '\n';
    }

    for (int i = 0; i < layers; ++i) {
        for (int j = 0; j < rows; ++j)
            delete[] a[i][j];
        delete[] a[i];
    }
    delete[] a;
}
```

[Файл прикладу](src/example-03-layer-sums.cpp)

Для розміру `2 2 3` суми шарів — `6` і `12`.

## Спільні вимоги до індивідуальних завдань

- Зчитайте додатні `rows` і `cols`; створіть двовимірний динамічний масив `int** a` через `new[]` і зчитайте всі елементи. Перевірте правильність введення.
- Обробляйте матрицю вкладеними циклами. Виводьте результат із підписом; індекси рахуйте від нуля. Для сум використовуйте `long long`, для середнього арифметичного — `double`.
- Якщо потрібного елемента, рядка або стовпця немає, виведіть `немає`. За рівності кандидатів виберіть перший за порядком обходу: згори вниз, у межах рядка зліва направо.
- Звільніть кожен рядок через `delete[]`, а потім масив покажчиків, зокрема у випадку помилки введення елементів. Не використовуйте `std::vector` замість динамічного двовимірного масиву.

| 7 | Знайти стовпець із найменшою сумою елементів; вивести його індекс і суму. |
| 8 | Підрахувати кількість рядків, у яких усі елементи додатні. |
| 9 | Підрахувати кількість стовпців, у яких є хоча б один нуль. |
| 10 | Для кожного рядка обчислити середнє арифметичне ненульових елементів; якщо їх немає, вивести `немає`. |
| 11 | Знайти найбільший елемент матриці та його індекси. |

У варіанті 20 індекси пари — це індекси її лівого елемента. Якщо `cols = 1`, горизонтальних пар немає.

2. Чому перед виділенням пам’яті потрібно перевірити розміри масиву?
3. Чим `int**` із окремо виділеними рядками відрізняється від одного неперервного блоку елементів?
4. Які вкладені цикли потрібні для обходу рядків, стовпців і шарів?
5. Чому для `new[]` потрібно використовувати саме `delete[]`?
6. У якому порядку звільняють пам’ять двовимірного і тривимірного масивів?
7. Що станеться, якщо звернутися до елемента за межами масиву?
8. Як звільнити вже виділену пам’ять, якщо під час зчитування матриці сталася помилка?
