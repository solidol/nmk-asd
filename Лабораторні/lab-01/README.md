# Покажчики, масиви та динамічна пам’ять

## Мета роботи

Навчитися працювати з адресами й покажчиками, обходити масив через покажчик, виділяти та звільняти динамічну пам’ять у C++.

## Теоретичні відомості

Покажчик зберігає адресу об’єкта. Оператор `&` отримує адресу, `*` дає доступ до значення за адресою. Покажчик потрібно ініціалізувати до використання; порожню адресу позначають `nullptr`.

```cpp
int x = 10;
int* p = &x;
*p = 20; // тепер x == 20
```

Для масиву `a` вирази `a[i]` і `*(a + i)` позначають той самий елемент. У масиві з `n` елементів допустимі індекси від `0` до `n - 1`. Пам’ять, отриману через `new[]`, звільняють через `delete[]`. У звичайних програмах частіше використовують `std::vector`; тут ручне керування пам’яттю є темою роботи.

## Приклади

### 1. Зміна значення через покажчик

```cpp
#include <iostream>

int main() {
    int x = 10;
    int* px = &x;
    std::cout << "До зміни: " << x << ' ' << *px << '\n';
    *px *= 2;
    std::cout << "Після зміни: " << x << ' ' << *px << '\n';
}
```

Результат: `10 10`, потім `20 20`. Покажчик містить адресу `x`, а `*px` змінює значення `x`.

### 2. Динамічний масив та арифметика покажчиків

```cpp
#include <iostream>

int main() {
    int n;
    std::cout << "Кількість елементів: ";
    if (!(std::cin >> n) || n <= 0) {
        std::cerr << "Потрібне додатне ціле число.\n";
        return 1;
    }

    int* a = new int[n];
    for (int i = 0; i < n; ++i)
        *(a + i) = 2 * i + 1;

    for (const int* p = a; p != a + n; ++p)
        std::cout << *p << ' ';
    std::cout << '\n';

    delete[] a;
}
```

Для `n = 4` результат: `1 3 5 7`. Цикл обробляє рівно `n` елементів.

### 3. Пошук мінімуму у введеному масиві

```cpp
#include <iostream>

int main() {
    int n;
    if (!(std::cin >> n) || n <= 0) {
        std::cerr << "Потрібне додатне ціле число.\n";
        return 1;
    }

    int* a = new int[n];
    for (int* p = a; p != a + n; ++p) {
        if (!(std::cin >> *p)) {
            std::cerr << "Помилка введення.\n";
            delete[] a;
            return 1;
        }
    }

    int minimum = *a;
    for (const int* p = a + 1; p != a + n; ++p)
        if (*p < minimum) minimum = *p;

    std::cout << "Мінімум: " << minimum << '\n';
    delete[] a;
}
```

Для введення `4` та `7 -2 5 -2` результат: `Мінімум: -2`. Початкове значення взято з першого елемента, тому приклад працює і для `n = 1`.

## Спільні вимоги до індивідуальних завдань

- Зчитати додатне ціле `n`, виділити `int* a = new int[n]` та зчитати `n` цілих чисел. Перевірити правильність введення.
- Обробити масив через арифметику покажчиків (`*(a + i)` або рухомий покажчик). Вивести результати з підписами.
- Якщо потрібного елемента або пари немає, вивести `немає` замість значення чи індексу. Індекси рахувати від нуля. Якщо кілька кандидатів однакові, обрати перший, крім випадків, де явно вказано «останній».
- Перед завершенням звільнити пам’ять через `delete[] a`. Не виходити за межі масиву; не використовувати `std::vector` або автоматичний масив замість динамічного.
- Для сум застосовувати `long long`. Для середнього арифметичного застосовувати `double`.
